pop() löscht das letzte Element aus einem Array und gibt es zurück. Dieses Element wird aus dem Array entfernt.

push() fügt ein neues Element am Ende eines Arrays hinzu und gibt die neue Länge des Arrays zurück.

shift() entfernt das erste Element aus einem Array und gibt es zurück. Dieses Element wird aus dem Array entfernt.

unshift() fügt ein neues Element am Anfang eines Arrays hinzu und gibt die neue Länge des Arrays zurück.
